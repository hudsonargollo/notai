# Dark theme notes

Same layouts; tokens flip per DESIGN_SPEC §1. Specifics:
- Cards gain 1px border (rgba(245,234,216,.12)) since shadow contrast is weak on #1d1712.
- Accent text uses accent-deep-dark #e8a877; never light-theme accent on dark bg.
- Progress tracks surface-2 dark #362c22.
- Viewfinder identical in both themes (always dark chrome).
- Status bar / nav follow theme.
