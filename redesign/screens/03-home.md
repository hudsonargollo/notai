# Home (Início)

Replaces the bento dashboard. Vertical scroll, one column, 20px gutter.

1. **Header**: "Olá, {nome}" (Caprasimo 28) + month caption. Right: 40px avatar circle → Settings. No camera/crown icon buttons.
2. **Hero card**: caption "Gasto em {mês}" → amount Caprasimo 40 (count-up once) → progress bar vs monthly target → sub "de R$ {meta} planejados · faltam {dias} dias". Bar accent2, danger if over.
3. **Insight card** (max 1 on Home): accent2-soft fill, asterisk glyph, one factual sentence + optional one-line suggestion. Signed caption. Tap → Insights tab.
4. **Orçamentos** section: header + "Editar" ghost. 3 top category rows inline (see 05-budgets.md). Row: label + spent/limit (tabular) + 6px progress.
5. **Recentes**: single card, flat hairline-separated rows (icon disc, merchant + category, amount + date). Row tap → Capture screen in edit mode. "Ver tudo" ghost at end.
6. **Bottom nav**: Início / [Capture ●] / Insights / Ajustes per spec §5.

Empty state: Caprasimo headline "Nada por aqui ainda." + body "Capture seu primeiro cupom." + arrow toward the capture button. No shopping-bag icon at 20% opacity.
